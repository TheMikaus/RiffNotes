# RiffNotes v0.6.10

This release adds FLAC workflow coverage and a practice-level multitrack bulk mixdown path for numbered take folders.

## Highlights

- Added FLAC practice-file support alongside WAV/WAVE and MP3.
- Expanded Convert to MP3 so WAV/WAVE/FLAC recordings can be converted in place while keeping notes and sections linked.
- Added numeric-folder multitrack detection for selected practices (folders like `12`, `13`, `14`).
- Added a main-panel `Bulk mixdown` action that appears only when numbered multitrack folders are detected.
- Added a multitrack mixdown preview dialog showing per-folder output, skip status, and archive target.
- Bulk mixdown writes stereo `number.wav` outputs to the practice root and moves source numeric folders into `mixed_Down`.
- Added `mixed_Down` to ignored practice-folder names so archived sources do not appear as practices.
