# RiffNotes v0.6.9

This release adds direct Google Drive sync paths, clearer first-run setup, and cancellable sync operations with live progress updates.

## Highlights

- Added direct Google Drive upload/download for selected practices.
- Initialize Sync now lets the user choose Drive API mode or local sync-folder mirror mode.
- Initialize Sync now copies inner contents when the local and Drive folder names match, so the folder layout stays aligned.
- Added live sync status updates during long-running transfers.
- Added cancel support for uploads and Initialize Sync.
- Prompt for a display name on first launch, seeded from the current Windows user name when available.
- Added FLAC practice-file support alongside WAV/WAVE and MP3.
- Expanded Convert to MP3 so WAV/WAVE/FLAC recordings can be converted in place while keeping notes and sections linked.

## Notes

Canceled syncs do not roll back files that were already copied. Re-running the same sync later will skip files that are already up to date when only changed files are copied.
